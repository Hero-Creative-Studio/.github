Hero Creative Studio (HCS) entwickelt FiveM-Scripts und Interfaces für Server unter ESX, QBCore und Qbox. Die Shop-Resources haben eigene NUI, serverseitige Checks und eine `config.lua`. Das Team übernimmt zusätzlich UI/UX, Webdesign und Custom-Systeme.

Kauf über Tebex, Download über das [Cfx-Portal](https://portal.cfx.re). Support über Discord-Tickets.
